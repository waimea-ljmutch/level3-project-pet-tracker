# Project Final Review and Reflection

## Addressing Relevant Implications

### Aesthetics

I kept the design simple and consistent across all pages. I used similar layouts, buttons, and forms to make the website look clean and easy to use.



### Usability

I made the website easy to navigate by creating clear pages for logging in, reporting pets, viewing posts, and messaging owners. I also used simple labels and error messages to help users understand what to do.



### Future Proofing

I used a database and separate pages so new features could be added later. In the future, features such as pet photos, maps, and reward systems could be added.


### Functionality

I successfully created the main features of the system, including user accounts, login/logout, reporting lost pets, editing and deleting reports, and sending messages. Testing helped make sure these features worked correctly.


### Accessibility

I used clear labels, simple language, and easy navigation throughout the website. The design is simple enough for users of different ages and experience levels.


## Overall Review

Overall, I am happy with how my project turned out. Most of the main features work correctly, including signing up, logging in, creating pet reports, viewing reports, editing reports, and deleting reports. Testing helped me find and fix several issues throughout development. I improved features such as login error messages, delete confirmations, and form usability based on feedback and testing. One feature that I was not able to fully complete was the inbox system, as messages are not displayed correctly. If I had more time, fixing the inbox feature would be my main priority. I would also like to add features such as pet photos and maps in the future.
Overall, the project was successful and met most of the requirements and goals that I set at the start of the project.
